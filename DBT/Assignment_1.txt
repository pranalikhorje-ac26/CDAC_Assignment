3.Write the SQL command to create a table Books with the following fields:
   - book_id (Primary Key, INT)
   - title (VARCHAR(150))
   - author_id (Foreign Key referencing Authors)
   - published_year (YEAR)
   - available_copies (INT)


create table Books(book_id int primary key,
    title varchar(150),
    author_id int,
     published_year year,
     available_copies int,
     foreign key(author_id) REFERENCES Author(author_id));

   - member_id (Foreign Key referencing Members)
   - book_id (Foreign Key referencing Books)
   - borrow_date (DATE)
   - return_date (DATE)
  13.Write a SQL query to create a foreign key & primary key relationship between two tables.

 create table Borrow_Records(record_id int primary key,
                member_id int,
                book_id int,
                borrow_date date,
                return_date date,
                foreign key (member_id) REFERENCES Members(member_id),
                foreign key (book_id) REFERENCES Books(book_id));
